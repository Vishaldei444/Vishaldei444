<details open>
<summary><h2>🐍 &nbsp;Contribution Snake</h2></summary>

<br/>

> ⚙️ **One-time Setup:** Create `.github/workflows/snake.yml` in your profile repo with the content below, then push. The snake auto-regenerates daily via GitHub Actions.

<details>
<summary>📄 <strong>snake.yml — click to expand workflow</strong></summary>

```yaml
name: Generate Snake

on:
  schedule:
    - cron: "0 0 * * *"   # Runs daily at midnight UTC
  workflow_dispatch:        # Allows manual trigger

jobs:
  generate:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - name: Generate Snake Animation
        uses: Platane/snk@v3
        with:
          github_user_name: ${{ github.repository_owner }}
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark

      - name: Push to output branch
        uses: crazy-max/ghaction-github-pages@v3.1.0
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

</details>
